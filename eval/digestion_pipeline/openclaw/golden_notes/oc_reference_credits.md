# OpenClaw — Credits, Name Origin, and License

## Overview

This note captures the OpenClaw project's origin story, contributor attribution, and license, mirroring the `reference/credits` source page. It explains the project name (CLAW + TARDIS), the three credited makers (Peter Steinberger, Mario Zechner, and the "Clawd" space-lobster persona), the named core contributors and their areas, and the project's MIT license. It is a small, attribution-focused reference page that the rest of the corpus points back to for provenance and licensing.

## The name

`OpenClaw = CLAW + TARDIS`, "because every space lobster needs a time and space machine." The name combines a "claw" (the lobster motif that runs through the project's branding) with TARDIS (the time-and-space machine), per the source page.

## Credits

The page credits three makers:

- **Peter Steinberger** ([@steipete](https://x.com/steipete)) — Creator, "lobster whisperer".
- **Mario Zechner** ([@badlogicc](https://x.com/badlogicgames)) — Pi creator, security pen tester.
- **Clawd** — "The space lobster who demanded a better name." Clawd is the project persona credited with prompting the rename.

The handle text and link targets are reproduced verbatim from the source (note that Mario Zechner's displayed handle is `@badlogicc` while the link points to `https://x.com/badlogicgames`).

## License

The project license is **MIT** — "Free as a lobster in the ocean." The page closes with the epigraph: *"We are all just playing with our own prompts." (An AI, probably high on tokens)*. The MIT license is what governs the published OpenClaw npm package and the broader monorepo; vendored third-party assets that the project bundles (for example the Apple device-identifier database) are separately MIT-licensed under their own upstream terms.
