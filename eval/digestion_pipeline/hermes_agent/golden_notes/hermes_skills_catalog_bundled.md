# Hermes Agent — Bundled Skills Catalog

## Overview

This is the **navigation index of the bundled skills that ship with Hermes Agent** — the built-in skill library copied into `~/.hermes/skills/` on install, grouped by category from `apple` through `yuanbao`. Each catalog entry is a `SKILL.md` the agent can load and invoke; this note enumerates the shipped skills with their one-line descriptions and in-repo paths verbatim from the reference, so a reader can discover what the agent can do out of the box. Hermes **also syncs bundled skills on `hermes update`**, but the sync manifest respects local deletions and user edits — if a skill listed here is missing from a profile's `~/.hermes/skills/` tree, it is still shipped with Hermes and can be restored with `hermes skills reset <name> --restore`. If a skill is missing from this list but present in the repo, the catalog is regenerated by `website/scripts/generate-skill-docs.py`.

This is the **always-bundled** half of the skills catalog; the install-on-demand counterpart lives in the companion optional-skills catalog note. The skills *concept* (what a skill is, the `SKILL.md` format, how skills are invoked), the skills hub/curator, and the work-with-skills how-to are owned by the skills feature pages and linked below — this note is the reference enumeration, not the feature prose. It also folds in a short **automation-blueprints gallery** pointer (the ready-to-run automations are themselves skills with a blueprint frontmatter slot).

## Automation Blueprints Gallery

The reference also ships an **Automation Blueprints** gallery — ready-to-run automations that are themselves skills with a `metadata.hermes.blueprint` block in their `SKILL.md` frontmatter. You pick one, fill in a couple of fields, and Hermes schedules it as a cron job with **no cron syntax required**. The catalog gallery is rendered client-side (the `<AutomationBlueprintsCatalog />` component), so the live list is browsed in-product rather than enumerated here.

Every blueprint works from **every surface**:

- **Dashboard / desktop app** — open the Cron page, switch to the **Blueprints** tab, fill the form, and click *Schedule it*.
- **CLI, TUI, and messengers** — type `/blueprint <name>` (e.g. `/blueprint morning-brief`) and Hermes asks for what it needs one question at a time, then schedules it. The name match is forgiving (a prefix or near-spelling resolves); power users can skip the questions inline: `/blueprint morning-brief time=08:00`.
- **Desktop app** — click **Send to App** on any blueprint and it opens with the command pre-loaded in the composer.

Blueprints never schedule anything silently — you always confirm before the job is created, and created jobs are managed anytime with `/cron`. To write your own, a blueprint is just a skill with a `metadata.hermes.blueprint` slot in its `SKILL.md` frontmatter — see the Creating Skills → Automation Blueprints build guide (owned by SP17) for the slot schema and how to publish one.
