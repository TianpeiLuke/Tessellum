## Scope

The provider-and-setup how-to guides: connecting Hermes to local LLM runtimes (llama.cpp/MLX on Mac,
Ollama), cloud/native providers (Google Gemini, AWS Bedrock, Microsoft Foundry/Azure), subscription/OAuth
providers (xAI Grok, MiniMax, Nous Portal), the cross-cutting OAuth-over-SSH transport pattern, and the
limited-time free Nemotron 3 Ultra walkthrough. Source = 10 mirrored pages in `inbox/hermes_agent_docs/guides/`
(all substantive). **P3 / guides** — these are task scripts that link DOWN to the provider concepts owned by
SP09 (`provider-routing`/`fallback`/`credential-pools`) and SP14 (`integrations/providers`, `nous-portal`),
and link UP to the config surface (SP02 `hermes_model_aux_provider_config`, `hermes_config_files_precedence`).

## Content Strategy

- **One BB per note.** All ten guides are step-by-step provider setup procedures → procedure notes, EXCEPT
  `azure-foundry.md` which is >2500w and mixes a setup procedure with an Entra-ID keyless-auth model + a
  reference (config shapes, credential-resolution order, env-var table) → SPLIT into 2 (proc + model). See
  Split Decisions.
- **Do NOT duplicate** content owned by other sub-plans → **link-outs**, not copied content: the AI-provider
  catalog + Nous Portal subscription concept (SP14 `integrations/providers`, `integrations/nous-portal`),
  provider-routing/fallback/credential-pool internals (SP09), the `config.yaml` model/provider/aux settings
  reference (SP02 `hermes_model_aux_provider_config`), the env-var master table (SP21), voice-mode/TTS
  feature pages (SP08), cron/batch feature pages (SP06).
  2026-06-15; no collision. Captured via `/tessellum-capture-term-note` in Phase 0 BEFORE the digest notes
  that link it (Notes 10, 11). All other concepts are existing verified terms (LINK) or other-SP forward-refs.
- **Collision (augment): `term_api_gateway.md` (active) is the generic networking concept, NOT Hermes' Tool
  Gateway / messaging gateway** — a master-caution LIKE false-positive. The Nous-Portal Tool-Gateway concept
  is owned by SP14 (`term_nous_portal`) / SP05 (`term_tool_gateway`); SP15 LINKs forward, does not recreate.
