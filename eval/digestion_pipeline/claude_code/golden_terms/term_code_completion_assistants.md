# Code Completion Assistants - AI-Powered Inline Code Suggestions

## Definition

**Code completion assistants** are AI tools that offer code completions, suggestions, and inline assistance as developers type, focusing on enhancing the coding experience without taking over the entire development process. They are reactive (triggered by typing), generate single-line to multi-line completions, and operate as a supercharged auto-complete rather than an autonomous agent.

## Context

- **Deployment**: IDE plugins for VS Code, JetBrains; CLI integration
- **Distinction from agents**: Code completion = reactive suggestions while typing; autonomous agents = proactive multi-step task execution

## Key Characteristics

- **Real-time suggestions**: Automatically generated as developer types, based on existing code and comments
- **Variable scope**: Ranges from single-line completions to fully formed functions
- **Context-aware**: Uses file content, imports, comments, and nearby code for better suggestions
- **Best practices for better results**:
  - More context = better suggestions (don't start with blank files)
  - Add import statements first to signal intent
  - Use full sentences in comments (not fragments)
  - Code-comment style like API docs produces better results
